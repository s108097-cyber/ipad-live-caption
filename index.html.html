限制說明
  • 這是單一 HTML 網頁，不需要後端或 API 金鑰；語音辨識由瀏覽器／其語音服務提供，翻譯使用公開的 MyMemory 翻譯服務。
  • 免費翻譯服務有使用量、速度、可用性及隱私方面的限制，不適合機密內容；服務可能改變或暫時不可用。
  • 自動偵測原文語言不是所有瀏覽器都支援，因此此版本需要手動選擇語言。
  • 若瀏覽器沒有 SpeechRecognition 功能，本程式無法自行辨識語音；請改用支援該功能的瀏覽器／原生 App。
  • 字幕面板只能在本網頁內拖曳，不能覆蓋在 YouTube 或其他 App 上方。切換到背景後也可能停止辨識。
